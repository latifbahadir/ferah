# Rakip Analizi

| Araç | Güçlü yanı | Eksik / Ferah'ın fırsatı |
|---|---|---|
| CleanMyMac | Kapsamlı, cilalı arayüz | Ücretli, ağır, geliştirici çöpünde sığ, kararları açıklamıyor |
| AppCleaner | Basit, kalıntılarıyla uygulama kaldırma | Sadece kaldırma; "kullanılmıyor" önerisi yok |
| Pearcleaner | Açık kaynak, modern kaldırıcı | Geliştirici çöpü ve büyük dosya analizi sınırlı |
| DaisyDisk / GrandPerspective | Disk görselleştirme | Öneri/gerekçe yok, temizlik akışı yok |
| OnyX | Sistem bakım araçları | Teknik, öneri tabanlı değil |
| DevCleaner for Xcode | Xcode çöpünde iyi | Yalnızca Xcode |

## Farklılaşma

1. **Açıklanabilir öneriler** — gerekçe + güvenlik seviyesi + güven skoru.
2. **Geliştirici ekosistemine derinlik** — Xcode, Node, Docker, Rust, Python, Gradle, CocoaPods tek yerde.
3. **Sürekli ferahlık** — tek seferlik tarama değil, menü çubuğu + kurallar + bildirimler.
4. **Onay kırmızı çizgisi ve geri alma** — güven temelli tasarım.
5. **Açık kaynak + CLI** — şeffaf ve betiklenebilir.
