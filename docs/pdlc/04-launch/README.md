# 04 — Lansman

Her sürüm için `release-notes/vX.Y.Z.md` dosyası oluşturulur ve GitHub Release açıklaması olarak kullanılır.

## Lansman kontrol listesi

- [ ] Milestone'daki tüm issue'lar kapalı veya bir sonraki milestone'a taşındı
- [ ] `CHANGELOG.md` güncellendi
- [ ] Sürüm notu yazıldı (`release-notes/`)
- [ ] Release artefaktı yayınlandı (bkz. [SDLC release süreci](../../sdlc/06-release/release-process.md))
- [ ] README'deki durum/özellik tablosu güncellendi
